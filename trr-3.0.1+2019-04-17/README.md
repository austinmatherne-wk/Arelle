# Inline XBRL Transformation Rules Registry

This repository contains the source for the Transformation Rules Registry.

The different versions of the registry are maintained as branches within this
repository:

* master = latest development version (currently v4)
* 3.0.0 = TRRv3
* 2.0.0 = TRRv2
* 1.0.0 = TRRv1

CI output for this repository can be found at https://base-spec.ci.xbrl.org/trr/
